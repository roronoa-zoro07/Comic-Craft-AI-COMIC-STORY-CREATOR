Project Summary
ComicCraft is a web-based application that uses AI to generate personalized comic book stories and illustrations from user-provided prompts.

Technology
FastAPI + Uvicorn
HTML, CSS and Jinja2
Gemini 1.5 Flash for structured 5-panel outlines
Gemini 1.5 Pro for narration and dialogues
Stable Diffusion via Hugging Face Diffusers for comic illustrations
FPDF for PDF export
Main Workflow
User Input → Gemini Flash → Gemini Pro → Stable Diffusion → Layout Builder → Comic Preview → PDF Export → Export Success

This package has been updated to follow the supplied ComicCraft documentation and the AI/ML/Gen-AI project-template folder structure.
